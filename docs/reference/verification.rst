Verification and the BAU case
=============================

P12 assembles 16 acceptance-criterion evidence rows, the synthetic BAU comparison, monitoring value,
owner-contractor exchange, measured small-case performance, and replay evidence. The report is
`notes/reports/p12-verification.md`; the machine record is `notes/reference/p12-verification.v1.json`.
Field calibration and the 10,000-segment scale target remain named gaps, so the recommendation is an
internal prototype release candidate, not a production or field-calibrated release.
