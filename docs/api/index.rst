API reference
=============

The API pages are generated from the public Python package and its typed models. They list
signatures, parameter types, and return values. Contract behavior is documented in
:doc:`../reference/index`; this section is the callable surface.

If you are new, read :doc:`../getting-started/index` and :doc:`../concepts/index` first. The API is
not a substitute for the model and privacy boundaries.
